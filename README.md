## About

Frontend / web developer. I like building small, useful things that run in the browser — mostly Chrome extensions, sometimes web apps, and the occasional bug hunt in other people's extension code.

Right now I'm learning the modern frontend stack (React / TypeScript) and fixing bugs wherever I can find them.

## Projects

### [Chess-See](https://github.com/heloIJS/chess-see)

Local Stockfish HUD for Chess.com and Lichess — arrows, eval, and a humanizer, all running 100% on-device. No network analysis, no telemetry.

- Best-move arrows (+ optional 2nd / 3rd alternatives)
- Live evaluation chip next to the board
- "Humanizer" mode with configurable blunder chances
- No build step — just load unpacked

### [agent-reflex](https://github.com/heloIJS/agent-reflex)

Reusable Agent Skills for learning from failures, authoring skills, and auditing quality.

### Open source

- Fixed a switch fall-through bug in [alyssaxuu/omni](https://github.com/alyssaxuu/omni) (14k★ browser productivity tool) — clearing passwords was also silently opening the history page → [PR #140](https://github.com/alyssaxuu/omni/pull/140)
