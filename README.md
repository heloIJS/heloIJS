## 🚀 Featured project

### [Chess-See](https://github.com/heloIJS/chess-see)

> Local Stockfish HUD for Chess.com and Lichess. Arrows, eval, and humanizer. 100% on-device.

A Chrome MV3 extension that overlays a fully local chess engine on live games:

- 🟢 Best-move arrows (+ optional 2nd / 3rd alternatives)
- 📊 Live evaluation chip next to the board
- 🎲 "Humanizer" mode with configurable blunder chances
- 🔒 No network analysis, no external engine, no telemetry — everything stays on-device

```bash
# no build step, just load unpacked
git clone https://github.com/heloIJS/chess-see
```
